# LuckyBox Android Gateway

Отдельный SMS-шлюз. URL, ID устройства и секрет вводятся прямо на экране приложения. Ту же пару ID/secret сначала создайте во вкладке «Админ → Настройки». На Android необходимо выдать приложению разрешение SMS.

Устройство фильтрует отправителя `beelineOFD`, принимает только целые рубли, подписывает точное JSON-тело HMAC-SHA256 и отправляет heartbeat через WorkManager после перезагрузки. Если интернет временно недоступен, SMS остаётся в уникальной очереди WorkManager и отправляется повторно; сервер защищён от повторного зачисления.

Debug APK подходит для ручной установки и проверки. Для публичного распространения соберите release APK/AAB и подпишите собственным закрытым ключом. Секрет production-устройства рекомендуется хранить через Android Keystore и не переносить между телефонами.
