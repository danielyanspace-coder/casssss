# Мини-игры и проверка качества, 29 октября 2026

Исправлены общая верхняя линия обложек мини-игр, мобильный отступ 24 px
после поиска и подписи Краша/Апгрейда. Они используют существующий механизм
синтетических счетчиков `config.feed.synthetic`, а не измерение онлайна.
Названия остаются в разметке для экранных чтецов.

Исправлена обработка устаревших ответов поиска и пагинации, отмена отложенного
поиска при переходах и освобождение ссылок на старые плитки. При сетевом отказе
вместо бесконечной заглушки появляется кнопка «Повторить».

Сохранены исправления казино, которые уже были на рабочем сайте:
вертикальные обложки Live с разными первыми играми на полках, отсутствие
дублирующих карточек между страницами и немедленное открытие превью игры.
Усилен CSS-селектор заголовка Live: позднее общее правило скрытия подписей
больше не перекрывает его.

API получает `Cache-Control: no-store` и `X-Content-Type-Options: nosniff`;
отключен заголовок Express. Проверки безопасности используют отдельный
сервер с `DEV_MODE=false` и одноразовую базу, без реальных платежей.
CSV-выгрузки защищены от формул в пользовательских никах и комментариях:
опасные строки становятся текстом, числовые суммы остаются числами.

Проверки добавлены в GitHub Actions:

- `test:casino`: каталог, кеш и быстрые переходы с задержанными ответами.
- `test/casino-layout.mjs`: 320/390/599/768/1440 px, верхние края обложек,
  отступ от поиска, полные обложки и размеры видимого названия Live.
- `test/security-http.mjs`: доступ без входа, отсутствие служебных полей,
  изоляция игроков, cookie, кеш, Origin, выход и недоступность приватных файлов.
- `test/csv-security.mjs`: формулы, начальные управляющие символы,
  кавычки, разделители и сохранность отрицательных числовых сумм.
- Существующие API/UI тесты проверяют игры, кассу, меню, модальные окна,
  регистрацию и другие основные сценарии.

Локальный Chromium и HTTP-сервер запрещены песочницей (`Operation not permitted`).
Браузерную проверку выполняет CI. Код рабочей копии не означает обновление
сайта в `/srv/luckybox`: этот путь недоступен для записи из данной среды.
Отдельные изменения оптимизации старта в `/root/luckybox-startup` сохранены
и не смешаны с этим PR.

Первые подтвержденные результаты CI: геометрия прошла на всех пяти ширинах,
HTTP-безопасность - 163 проверки. На локальном сервере раннера с CPU x4:
готовность главной 1,89-2,87 с, открытие кейса 586-666 мс, обновление баланса
0,7-3,7 мс, ошибок JavaScript нет. Это не замер скорости рабочего домена.
Снимки и JSON доступны в артефакте `mobile-quality-results` задания `quality`.
