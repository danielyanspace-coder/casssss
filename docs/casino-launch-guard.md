# Контроль запуска игр

Релиз: release-20261101-launch-guard.

Экран запуска появляется до ответа API. Через 15 секунд выводится сообщение о долгом ожидании, через 30 — закрываемая панель действий. Событие iframe load убирает полноэкранную заставку, но не считается доказательством готовности игры. Кнопка «Чёрный экран?» доступна постоянно. Таймаут API 45 секунд, поздний ответ не монтирует iframe. Повтор только вручную, без смены режима демо/реальных средств; двойное нажатие блокируется. При закрытии удаляется iframe и очищаются таймеры. Авторизационная ошибка возвращает к входу.

Новых периодических HTTP-запросов, проверки всех игр, автоповторов и телеметрии нет. Существующий опрос баланса сохраняет частоту; во время ожидания API он не запускается. Добавка gzip к исходному модулю казино: 817 байт. Полная готовность сторонней игры без документированного события провайдера не определяется. Причина сбоя конкретного провайдера этим изменением не устанавливается.

Проверки: npm run test:casino; node test/casino-launch-guard.mjs; браузерные casino-launch-guard-ui.mjs и casino-release-ui.mjs (390/1280 px, отложенный ответ, пустой чёрный iframe, работающий canvas, повтор, закрытие, отсутствие автоматических запусков, частота баланса, ошибки JS).

Публикация: зависимости нового релиза, исходники и стили, затем HTML; сервер и база не меняются. Резервная копия: /srv/luckybox/backups/casino-launch-guard-20261101.
