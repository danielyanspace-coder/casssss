# LUCKYBOX: второй проход ускорения, 31 октября 2026

Новая версия применена на lucky-box.duckdns.org, nginx проверен и перезагружен, сервис luckybox перезапущен. Резервная копия предыдущей версии: /root/luckybox-before-speed2-20261031.

## Сохранение внешнего вида

Стили public/styles.css, отрисовка обложек public/covers.js, анимационный модуль public/motion.js и файл шрифта Loma совпадают с предыдущей версией побайтно. Изображения не пересжимались и не заменялись. Функция публичных счётчиков также побайтно прежняя.

Контрольные снимки главной на 390 и 1440 px дали **0 различающихся пикселей**. Для воспроизводимости использованы одинаковые публичные данные, дата, начальное состояние генератора декоративных случайных чисел и остановка анимаций на контрольном кадре только в тесте. На рабочем сайте анимации продолжают работать.

Артефакты: visual-before-390.png, visual-after-390.png, visual-before-1440.png, visual-after-1440.png, visual-parity.json.

## Что ускорено

1. Код админки вынесен в отдельный модуль. Его функции, права и разметка сохранены; модуль подгружается при открытии панели. Общий обработчик загрузки чеков оставлен доступным кассе. Повтор после сетевой ошибки не требует перезагрузки страницы.
2. Казино, встроенные слоты и тела юридических документов подгружаются при открытии соответствующего раздела. Для главной сгенерированы те же реквизиты и точная разметка подвала без загрузки всех документов. Тексты документов остаются в исходном legal.js, сборка берёт сведения из него.
3. Первоначальный каталог содержит сведения для полок, витрины и прежнего главного приза дня. Полные предметы и вероятности выбранного кейса приходят перед открытием его экрана, параллельно с загрузкой рисунков. До получения полного состава барабан не строится. Максимальные значения для бесплатного кейса и ежедневной витрины сохранены.
4. Добавлен публичный GET /api/cases/:id, возвращающий прежний publicCase без изменения чисел. Старый GET /api/config без специального заголовка по-прежнему возвращает полный каталог: старые вкладки и клиенты совместимы с сервером. Начальная компактная форма выбирается заголовком X-Case-Catalog: summary; ответ помечен Vary.
5. Начальные запросы конфигурации и пользователя запускаются прямо из маленького загрузчика, без ожидания графа модулей. Они передаются основному модулю один раз, только в памяти; повторных запросов и хранения ответа игрока в localStorage нет.
6. Сборщик явно предзагружает только обязательные общие зависимости главного модуля. Ленивые игровые и административные модули в эту предзагрузку не включаются.
7. Для неизменённого OTF добавлено транспортное gzip-сжатие. Файл шрифта не конвертировался, контуры, метрики и начертание не менялись. nginx отдаёт новые сборки с предсжатием и корректным Vary: Accept-Encoding.

Основной JS после gzip: 162 202 → 114 013 байт, примерно на 30% меньше. Начальный каталог в локальном сравнении: около 79 → 11 КБ после gzip, примерно в 7,5 раза меньше. Полные данные остальных кейсов больше не обязательны для первого экрана.

## Сравнение на опубликованном сайте

Старый и новый клиент сравнивались на одном домене и одном сервере, одним Chromium, в новых браузерных контекстах без предварительного кеша. Сеть не перехватывалась тестом. Порядок старой/новой версии чередовался. Для этого временно были доступны две страницы старой версии; после измерения они удалены.

| Показатель, медиана | До | После |
|---|---:|---:|
| Обычный профиль, LCP, 2 прогона каждой версии | 1,89 с | 1,80 с |
| Тяжёлый профиль, LCP, 3 прогона каждой версии | 4,71 с | 4,04 с |
| Тяжёлый профиль, снятие заставки/готовность интерфейса | 4,05 с | 3,50 с |

Тяжёлый профиль: 360×800, CPU ×6, ограничение загрузки 1,6 Мбит/с и заданная задержка 150 мс. Обычный: 1440×1000, без искусственного замедления.

Разброс LCP тяжёлого профиля: до 4,61–4,79 с, после 4,01–4,85 с. У новой версии медиана ниже примерно на 14%, но отдельный медленный прогон остался. Результаты не означают, что любой посетитель всегда будет видеть страницу за указанное число секунд. Это лабораторное сравнение, а не статистика реальных устройств. Небольшое изменение обычного профиля по двум прогонам не устанавливает статистически значимый выигрыш.

Данные: live-comparison.json. С предыдущими одиночными замерами на 4,5 с нельзя обращаться как с точным постоянным временем: для этого прохода проведено отдельное парное сравнение.

## Проверки

- case-catalog.mjs: все 69 записей метаданных и максимумы совпали с полной конфигурацией; полный состав выбранных кейсов совпал поле в поле; неизвестный ID даёт 404; полный старый API сохранён. Проверено также на опубликованном домене.
- startup-ui.mjs: загрузка при зависшем внешнем сервере шрифтов, вход/касса, восстановление после сетевого отказа, касание против свайпа.
- startup.mjs: 842 SVG соответствуют оригиналам, загрузка и повтор после ошибки, отмена открытия, разбор автономной сборки.
- speed-regression.mjs: Chromium и WebKit; обложки, прокрутка длинной страницы, открытие HD-кейса, ширина админки 320/390/1440; отсутствие ложного уведомления при входе и сохранение анимации настоящего первого пополнения.
- lazy-sections.mjs: модули не запрашиваются вместе с главной; все документы и подвал неизменны; казино открывается; все 14 разделов админки, CSV и карточка игрока работают.
- catalog-ui.mjs: один начальный запрос конфигурации и пользователя; повтор после 503 при загрузке кейса; полный состав до показа экрана; отменённая загрузка не открывает устаревший экран; ленивый раздел встроенных слотов работает.
- spin-speed-smoke.mjs: на отдельной тестовой базе предмет под указателем совпал с результатом настоящей прокрутки.
- visual-parity.mjs: пиксельное сравнение главной, 0 отличий на обеих ширинах.
- modules.mjs: импорты клиентских модулей сходятся.
- live-smoke.json: повторный проход опубликованной версии в Chromium и WebKit — без ошибок JavaScript и HTTP, битых загруженных изображений, ложной сцены пополнения и переполнения на проверенных ширинах. Проверены игровые переходы, касса, поиск банка и открытие админки.

На рабочем сайте не выполнялись ставки, подтверждения выплат, изменение балансов или настроек. Игровая математика, платёжные обработчики и рабочая база не менялись. Серверная правка касается только доставки уже публичного каталога.

## Файлы и сборка

Клиентская сборка: public/release-20261031-v2. Новый модуль панели: public/admin-ui.js. Новый публичный каталог: server/case-catalog.js и соответствующие GET-обработчики в server/app.js. Лёгкий подвал: public/legal-summary.js, генерируется tools/build-legal-summary.mjs при npm run build:client. nginx обслуживает папки release-* с готовыми gzip-файлами; старые сборки сохранены для уже открытых вкладок.

Откат: восстановить public и server/app.js из /root/luckybox-before-speed2-20261031, прежние package-файлы, сборщик и nginx-конфигурацию; nginx -t, reload nginx, restart luckybox. Новые неиспользуемые вспомогательные файлы после восстановления старой точки входа не участвуют в работе. Рабочую базу откатывать для этой правки не требуется.

Все замеры и административные скриншоты хранятся в /root/luckybox-speed2 и не публиковались.
