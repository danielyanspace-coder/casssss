# Сцена покупки фриспинов

Полная сцена работает и на сенсорных устройствах: сгусток, взрыв,
FREE SPINS, число и поштучная раздача жетонов сохранены.
Короткая версия остаётся только для prefers-reduced-motion.

Перед началом движения эмблема и жетон декодируются в PNG, слова и число
рисуются в canvas с металлической заливкой и глубиной, лучи рисуются в
отдельный bitmap. Во время движения эти слои меняют только transform
и opacity. Кеш ограничен 48 записями. Искры и монеты используют общий canvas
с существующим ограничением частиц и разрешения. Убрано чтение геометрии
движущегося сгустка на каждом шаге эмиттера. Подпись не анимирует letter-spacing.
При закрытии отменяются анимации и отложенные действия не заполняют ячейки;
спрятанная эмблема восстанавливается. Ошибка декодирования декоративного SVG
использует растровый жетон FS и не прерывает оплаченную серию.

Проверки: npm run test:modules, npm run test:startup,
node test/mobile-quality.mjs, node test/freespin-raster-ui.mjs.
Последняя проверка требует Chromium и WebKit Playwright: полный показ
10/20/30 на сенсорном экране, отсутствие SVG и фильтрованного текста в
движущихся слоях, точное число жетонов, отмена на пяти этапах, reduced motion.
Снимки и интервалы кадров: MOTION_RESULTS или /tmp/luckybox-freespin-results.
Это функциональная проверка и диагностические замеры, не гарантия FPS iPhone.
