# Повторный проход оптимизации клиента — 1 ноября 2026

## Применено

1. **Подготовка лент до прокрута.** Одинаковые элементы формируются одним фрагментом HTML. Замеры подписей/геометрии собраны в один callback следующего кадра: сначала чтения, затем записи сдвигов. Отменённая перестройкой разметки задача не обрабатывает удалённые ленты. Количество плиток, их SVG, случайные числа и положение под маркером сохраняются.
2. **Хвосты лент.** Дополнительные плитки обычного прокрута и серии фриспинов вставляются одним фрагментом вместо отдельных вставок. Состав, порядок, предел в 40 дополнительных плиток и последовательность случайных вызовов сохраняются.
3. **Рулетка.** В одном кадре сначала читается размер для положения шара, затем записываются трансформации. Формулы, координаты, звуки, количество кадров, easing и длительности не меняются.
4. **Каталог казино.** Объединяются только одинаковые незавершённые запросы лобби, домашних блоков и быстрых игр. После ошибки запрос допускает повтор. Завершённые Promise удаляются. Ответы покинутых экранов не вызывают повторный рендер. При открытии уже загруженного лобби и переключении на загруженную вкладку исключён второй одинаковый рендер. Запуски игр и операции кошелька не объединяются.

## Подтверждение результата

- Подготовка 1, 2 и 10 лент на 390px и 1280px: совпали все подписи/суммы, их размеры шрифта, трансформации, полная SVG/HTML-разметка с нормализованными уникальными ID и конечное состояние RNG. Контрольные снимки видимой области лент совпали побиксельно. В тесте статических снимков анимации временно отключались только тестовым CSS; продуктовый CSS не изменён.
- Для десяти лент callback подготовки: 20 → 1. На мобильной раскладке пересчёты layout: 10 → 2, пересчёты стилей: 20 → 3. Это подготовительные замеры, не частота кадров анимации.
- Wall-clock время тяжёлой подготовки сильно менялось между запусками. Дополнительно выполнен чередующийся замер старого/нового кода в одной странице; устойчивой кратной регрессии не выявлено. Процент ускорения всего сайта не заявляется.
- Обычный прокрут: 36 сценариев (1/2/10 лент, обычная/широкая/очень широкая область, витринная плитка и обе длительности). Совпали HTML, RNG, сдвиги, звуки и расписание анимации. Число вставок хвоста в сумме по этим стресс-сценариям: 1364 → 52.
- Рулетка: 45 сценариев, 18045 кадров, включая изменение ширины посреди вращения. Совпали положения шара/колеса, щелчки, конечные углы. Чтения геометрии после записи стилей: 18090 → 45 (одно оставшееся чтение на завершающем кадре каждого сценария).
- Конкурентные обращения к каталогу: двадцать вызовов объединяются в один запрос; независимые ключи, ошибки/повторы и освобождение завершённых запросов проверены.
- Браузерный сценарий «казино → кейсы → казино» при задержке ответа: запросы lobby 2 → 1, home 2 → 1. Повторное открытие кешированного лобби: замены содержимого 2 → 1. JavaScript-ошибок нет.
- Снимки основных разделов на двух ширинах, проверки кошелька/кассы/жестов в Chromium и WebKit, навигация/демо/жизненный цикл казино, технические проверки первого прохода, выход из кейса, модули и startup/автономная сборка прошли.
- Собранный релиз проверен на 390px/1280px: демозапуск тестовой анимированной страницы провайдера, обновление баланса, закрытие и повторный запуск без ошибок.
