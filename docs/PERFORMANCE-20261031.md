# LUCKYBOX: ускорение и исправления, 31 октября 2026

Изменения применены на https://lucky-box.duckdns.org. Сервис luckybox перезапущен; nginx успешно проверен и перезагружен. Рабочая база, игровые вероятности, расчёт выигрышей и настройки кассы не менялись. Функция публичных счётчиков сверена с резервной копией: её исходный код остался побайтно прежним.

## Что изменилось

- Убраны принудительная загрузка всех обложек через 1,5 секунды и прогрев рисунков всех тем. Изображения загружаются рядом с видимой областью; скрытые меню и подвал ожидают появления на экране.
- Для обложек и баннеров подготовлены адаптивные варианты высокого качества. Браузер выбирает размер по ширине экрана и плотности пикселей. Исходные большие изображения сохранены для больших экранов и высокого DPI.
- Следующий слайд загружается и декодируется перед переключением; текущий кадр остаётся виден до готовности следующего. Сохранены переходы и длительности слайдов.
- Рисунки в ленте и фоновые монеты загружаются как самостоятельные SVG, с теми же векторными путями. Лента больше не требует импорта множества тем и создания тысяч SVG-узлов на старте. Большая сцена предмета по нажатию по-прежнему использует полный HD-рисунок.
- Скольжение ленты переведено с изменения ширины и отступов на transform и opacity с перемещением соседних карточек. Эффект движения сохранён, пересчёт раскладки на каждом кадре исключён из этой анимации.
- Невидимые полки приостанавливают CSS-анимации; при возвращении в экран они продолжаются. Анимации в скрытой вкладке приостанавливаются. Видимые эффекты не отключаются.
- Код и CSS собраны и минифицированы; текст остаётся UTF-8. Готовые gzip-файлы отдаёт nginx, без повторного сжатия больших модулей на каждый запрос. Для остальных текстовых ответов увеличена степень gzip-сжатия.
- Независимые этапы запуска разделены на отдельные задачи. Числа форматируются через повторно используемый Intl.NumberFormat, цвета редкости кешируются.
- Принудительный ранний замер шапки заменён на ResizeObserver. Высота передаётся только панели кошелька и разделу бонусов, без изменения наследуемого CSS-свойства на корне всего документа.
- Иконки кассы и список банков готовятся при открытии кассы; повторные одновременные загрузки банков предотвращаются, при сетевом отказе допускается повторный заход.
- Исправлено ложное уведомление о пополнении после входа: эффект разрешён только при увеличении числа пополнений у того же реального аккаунта. Смена гостя на пользователя и смена аккаунта не считаются пополнением.
- Исправлены переполнение таблицы админки и сжатие шапки на узком экране. Проверены ширины 320, 390 и 1440 px.

## Замеры на опубликованной версии

Одинаковый Chromium, новый браузерный контекст без кеша; страница гостя, без ставок. Окно наблюдения: ожидание 10 секунд после появления первой карточки. До изменений — benchmark.json из первого аудита; после — production-final-benchmark.json.

| Показатель | До | После |
|---|---:|---:|
| LCP, слабый профиль | 11,31 с | 4,53 с |
| Самая длинная задача, слабый профиль | 971 мс | 447 мс |
| CLS, слабый профиль | 0,143 | 0,092 |
| Трафик за окно наблюдения, обычный профиль | 9,14 МБ | 1,08 МБ |
| Трафик за окно наблюдения, слабый профиль | 1,98 МБ | 0,76 МБ |
| LCP, обычный профиль | 2,28 с | 2,62 с |

Слабый профиль: 360×800, CPU ×6, ограничение загрузки 1,6 Мбит/с и заданная задержка 150 мс. Обычный профиль: 1440×1000, без искусственного замедления. Это отдельные лабораторные прогоны, не медианы реальных пользователей; небольшое различие на обычном профиле не устанавливает статистически значимое изменение скорости. Убедительное улучшение здесь — снижение трафика и более быстрый запуск при ограниченных ресурсах. Запуск на слабом профиле всё ещё занимает несколько секунд: гарантировать мгновенную загрузку при любой сети и на любом устройстве эти результаты не позволяют.

Размеры трафика относятся к завершившимся ресурсам за окно наблюдения. За этот период слабый профиль может успеть загрузить меньше ресурсов, чем обычный; это не сравнение окончательного веса всей длинной страницы.

## Проверки

- startup-ui.mjs: интерактивность без ответа внешнего сервера шрифтов; вход и касса; восстановление после сетевого отказа; корректное касание кейса и отличие касания от свайпа.
- startup.mjs: 842 SVG совпадают с оригинальными; объединение запросов, повтор загрузки темы, первоначальные API-запросы, загрузчик кейса и отмена открытия; шаблон автономной сборки разбирается.
- modules.mjs: импорты клиентских модулей сходятся.
- speed-regression.mjs: Chromium и WebKit; загрузка первых и дальних обложек, открытие HD-кейса, отсутствие ложной сцены пополнения, ширины админки. Отдельно проверено, что настоящее первое пополнение всё ещё запускает сцену, а вход и смена аккаунта — нет. Эти изменения баланса сделаны только в тестовом состоянии браузера на локальной копии.
- spin-speed-smoke.mjs: реальная прокрутка на отдельной тестовой базе. Название предмета под указателем совпало с названием результата. Реальных ставок на рабочем сайте не совершалось.
- live-smoke.json: результаты повторной проверки опубликованного сайта, без финансовых операций.

Для финальных проверок обоих движков использован Playwright 1.64.1 с соответствующими установленными браузерами. Сравнительные замеры до/после выполнены одним прежним Chromium, чтобы сохранить сопоставимость.

## Сборка и откат

Исходники: /srv/luckybox/public. Генераторы: tools/responsive-images.mjs и tools/build-feed-art.mjs. Сборка: npm run build:images, затем npm run build:client после установки devDependencies. Артефакты сборки лежат в public/release-20261031; nginx-конфигурация синхронизирована с deploy/nginx.conf. Новые версии сборки следует выкатывать с проверкой согласованности HTML, модулей и предсжатых файлов.

Резервная копия исходных публичных файлов, package.json, package-lock.json, сборщика и nginx-конфигурации: /root/luckybox-before-speed-20261031. База в эту копию не включалась, поскольку задача меняет клиент и раздачу статики. При откате восстанавливаются исходные public, package-файлы, сборщик и nginx-конфигурация, затем nginx -t, reload nginx и restart luckybox. Рабочую базу восстанавливать для этого отката не требуется.

Сырые замеры, трассировка, результаты проверок и скриншоты: /root/luckybox-speed. Резервная копия и административные скриншоты не публиковались.
